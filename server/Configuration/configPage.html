Multiview

Start a video in Jellyfin Web, then select Multiview. Use Add stream to browse your libraries without leaving playback.

The web client script must also be installed. Follow README.md in the plugin distribution; installing the DLL alone does not add player controls.

Two streams stack vertically. Three use two upper panes and one larger lower pane. Four use a grid; larger groups fill balanced rows, up to nine streams.

Drag the arrow handles to move or resize. Focus a handle and use arrow keys for keyboard adjustments. Use Listen to select a single audio source.

Chrome is the primary target. Xbox WebView/Edge requires hardware verification. Roku is not supported by this web integration.
